ベトナム南部沖合230kmに浮かぶ**コンダオ島**は、かつて流刑地として使われていたため開発が遅れ、今も素朴なビーチが残る島です。フランス統治時代の監獄跡という重い歴史と、ウミガメが産卵に訪れる美しい海を同時に持つのが特徴。日本の旅行会社もここ数年ツアーを出し始めたばかりで、日本語の情報はまだ多くありません。

## 行き方

- **飛行機**：成田・関西からホーチミン（タンソンニャット空港）へ直行便（ANA・JAL・ベトナム航空、約6時間）。
- **ホーチミンからコンダオへ**：ホーチミンの国内線専用ターミナル（T1）からVASCO（ベトナム航空グループの国内線）でコンダオ空港へ約1時間10分。国際線（T2）とは別の建物のため、乗り継ぎには最低3時間必要です。
- コンダオ行きの便はほぼ午前〜昼過ぎに集中しており、夜の便はありません。日本からの直行便の到着時間と合わないため、**ホーチミンで1泊してから翌朝の便でコンダオへ向かう**のが現実的です。
- **島内の移動**：空港からコンソンの町まで車で約20分。町なかはレンタルバイクか徒歩、国立公園エリアへはツアーボートが基本です。

## ベストシーズン

| 月 | 推し度 | 特徴 |
|---|---|---|
| 1月 | ◎ | 乾季・海が穏やか |
| 2月 | ◎ | 乾季・ベストシーズン |
| 3月 | ○ | 気温が上がり始める |
| 4月 | ○ | 暑くなるがダイビングには good |
| 5月 | ○ | ウミガメの産卵シーズン入り、ただし雨も増え始める |
| 6月 | ○ | ダイビングのベストシーズン |
| 7月 | ○ | ダイビングのベストシーズン、ウミガメ産卵も見られる |
| 8月 | × | 雨季・海が荒れてボート欠航のリスクが高い |
| 9月 | × | 雨季・ウミガメ産卵のピークだが海況が不安定 |
| 10月 | × | 雨季 |
| 11月 | ○ | 乾季入り |
| 12月 | ◎ | 乾季・海が穏やか |

**狙い目は12〜2月**。海が最も穏やかで、ボートツアーも欠航しにくい時期です。ウミガメの産卵（5〜9月、ピークは7〜9月）を見たい場合は雨季と重なるため、ボート欠航のリスクを承知の上で計画してください。

## おすすめビーチ・スポット

- **プーハイ監獄跡**：1862年築、コンダオに11あった収容所の中で最大級。フランス統治時代の「タイガーケージ」が残る歴史的建造物
- **ダムチャウビーチ**：空港から約1kmの静かなビーチ。人が少なく、到着日や最終日の空き時間に立ち寄りやすい
- **ベイカイン島**：コンダオ国立公園内の島。ウミガメの産卵地として知られ、1883年建造の灯台までのトレッキングも楽しめる
- **コンダオ博物館**：町なかにある博物館。島の監獄の歴史を知ってから各史跡を回ると理解が深まる
