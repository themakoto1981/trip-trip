フィリピン中部ビサヤ諸島の**シキホール島**は、昔から「魔女と癒しの島」と呼ばれてきた小さな島です。白砂のビーチと、滝つぼにブランコが下がるカンブガハイ滝、崖から飛び込めるサラグドゥーンビーチ、そして夕日の名所パリトンビーチがあります。観光地化が進みすぎていない静かな島時間を味わいたい人に向いています。

## 行き方

日本からの直行便はなく、**セブ経由で高速船**に乗ります。成田・関西からセブへ直行便で約4時間半〜5時間40分、そのあとセブ市内のピア1港からOceanJetの高速船でシキホール島のラレナ港へ（ボホール島のタグビラン経由、約4〜5時間）。セブ到着が午後になるため、**セブで1泊してから島へ渡す**のが現実的です。

- **フェリー**：セブ発は朝と昼過ぎの2便、シキホール発も朝と午後の2便（日によって異なります）<br><a class="schedule-tag" href="https://12go.asia/en/travel/cebu/siquijor/?z=17114820" target="_blank" rel="noopener noreferrer">12go.asiaでフェリーの最新スケジュール</a>
- **ビザ**：日本国パスポートは不要（30日以内の観光目的）。
- **島内の移動**：ラレナ港から主要リゾートのあるサンファン地区まで車で約45分。島内はトライシクルのチャーターかホテル手配のバン・専用車が基本です。配車アプリGrabは玄関口のセブ市内で使います。

## ベストシーズン

| 1月 | ◎ | 乾季、涼しく快適 |
| 2月 | ◎ | 乾季、天気が安定 |
| 3月 | ◎ | 乾季、晴天が多くビーチ向き |
| 4月 | ◎ | 乾季、海も穏やか |
| 5月 | ○ | 乾季終盤、暑さが増す |
| 6月 | △ | 雨季入り、雨が増える |
| 7月 | △ | 雨季 |
| 8月 | △ | 雨季 |
| 9月 | △ | 雨季 |
| 10月 | △ | 雨季 |
| 11月 | ○ | 雨季明け、混雑前で宿が安め |
| 12月 | ◎ | 乾季入り、涼しく快適 |

**狙い目は12〜4月**。乾季は天気が安定し、滝もビーチも青空の下で楽しめます。雨季は高速船が欠航することもあるため、帰国前日に島を出る日程にしておくと安心です。
