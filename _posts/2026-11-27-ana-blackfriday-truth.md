ANAでは2026年11月25日〜30日まで、国際線ブラックフライデーセールを開催しています。

公式サイトには魅力的な価格が並んでいますが、実際に航空券を検索するといくらになるのでしょうか。今回は、同じ旅行日程で東南アジア7都市の航空券を調べてみました。

## 実際に検索した航空券の価格

以下の条件でANA公式サイトから検索しました。

- 出発日：2027年2月11日
- 帰国日：2027年2月14日
- 人数：1名
- クラス：エコノミー
- 往復・税込

| 行き先 | 往復航空券 |
|---|---|
| バンコク | 159,540円 |
| マニラ | 113,890円 |
| ホーチミン | 203,730円 |
| ハノイ | 271,030円 |
| シンガポール | 219,920円 |
| ジャカルタ | 93,040円 |
| クアラルンプール | 123,370円 |

都市によって、価格にかなりの差があることが分かります。

## 過去のセールと比較

バンコク・マニラの2路線は、過去のセール開催分の価格も記録していたので並べてみました。

| 開催時期 | バンコク | マニラ |
|---|---|---|
|  | **バンコク** | **マニラ** |
| 2025年12月 | 31,000円<br>(58,400円) | 23,000円<br>(40,600円) |
| 2026年4月 | 19,900円<br>(52,500円) | 14,900円<br>(35,900円) |
| 2026年7月 | 9,800円<br>(76,800円) | 17,000円<br>(62,000円) |
| 2026年9月 | 21,500円<br>(76,100円) | 17,700円<br>(56,300円) |
| 2026年10月 | 12,000円<br>(66,600円) | 22,000円<br>(60,600円) |
| ブラックフライデー<br>（2026年11月） | 14,000円<br>(78,000円) | 15,000円<br>(58,000円) |

燃油特別付加運賃（燃油サーチャージ）は2か月ごとに見直される費用で、セールの値引きとはまた別に、市場の燃料価格に応じて変動します。2026年5月には大きな値上げもあったため、この表ではサーチャージを除いた金額を先に、サーチャージを含めた実際の支払い額をカッコ内に記載しています。

## まとめ

今回調べた限り、都市によって価格には大きな差がありました。また「ブラックフライデー」だからといって、必ずしも毎月のセールより安くなるわけではないようです。

今後もセールのたびに価格を確認し、本当の買い時を改めて紹介していきます。
